# 肉呆爱动效 1.7 调研预览版

开发构建版本：**1.7.0-preview.1**（未发布；当前推荐下载已公证的 [1.7 正式版](https://github.com/rddmwmddr/roudai-aidongxiao/releases/tag/v1.7.0)），App **1.7（build 13）**。在既有23个调研入口之外，新增4个纸张与拼贴模板，以及可编辑文字、中途停顿、本地音效导入和自动卡点。

## 1.6 新增入口

- 「动效 → 纸张与拼贴」：文字匹配剪辑、纸张剪贴、折纸展开、杂志剪字。纸纹使用原创无字素材，文字排版仍可编辑。
- 暂停后双击纸面文字，复制、粘贴、修改，再点击「应用文字」。导入的截图是图片，不会自动OCR。
- 「这一镜 → 中途停顿与音效」：输入位置和秒数，或拖动滑块；添加停顿会延长总时长，保留原动效速度。
- 导入本地音效，编辑起点、裁切、音量、速度和淡入淡出。自动节拍支持数字变化快慢、纸张切换、剪字入场与折纸起点；其他模板可手动放置音效。
- 声音与画面共享项目配置，导出为H.264视频与48kHz双声道AAC。原生AAC已处理编码延迟及音频头兼容问题，成片实际解码通过。
- 安装盘「演示工程与CSV/纸张与拼贴」内打开「可编辑文字-中途停顿-音效.dmboard」。修改前请将工程复制到本地。

完整说明：`docs/PAPER.md`、`docs/MOTION_MEDIA.md`。默认1920×1080、60fps，支持修改。

新增 20 个调研基础模板和 3 个可编辑组合预设，原有 733 个动效保留。演示工程与 CSV 均为明确标注的演示数据，不代表真实研究结论。

## 安装与入口

- macOS 13 及以上，Apple 芯片和 Intel 通用。
- 将「肉呆爱动效-调研预览版.app」拖到 Applications。它使用独立的开发版应用标识，可与正式版共存。
- 此预览包使用本地临时签名，**未经 Developer ID 签名及 Apple 公证**。macOS 可能阻止直接打开；有公证安装要求时请使用 1.7 正式版。
- App 中按 ⌘O 打开安装盘「演示工程与CSV/调研数据/重构调研-全部模板.dmboard」。先把演示工程复制到本地再编辑保存。
- 点击片段上方动效胶囊，在「调研数据 · Opus」「调研组合预设」中选择。右上角「这一镜」编辑数据、样式、时间线与输出。
- 默认 1920×1080、60fps。模板配置、中文字体、数据与秒级动画逻辑由预览和导出共用。

## 新增内容

前后对比、点阵占比、动态排名、数字变化；看板卡片、问卷、桑基、漏斗、散点气泡、热力日历、原声卡片、追踪时间轴、图片/视频分屏、堆叠面积；个体连续分组、样本拉远、动态解说、城市地图、决策路径、产品场景聚焦；以及三个叙事组合预设。

支持表格与 CSV、统一 AI 配置、撤销重做、保存重开、逐帧 MP4 导出。AI 本地调用和各模板数据口径详见仓库 `docs/OPUS.md`。

产品场景为分层视差；字幕使用导入时间戳或手动时间点，不含自动口播对齐。YouTube 参考未读取连续画面，实现依据需求规格。地图使用本地 Natural Earth 陆地轮廓。
