# 肉呆爱动效 1.4 调研预览版

新增 20 个调研基础模板和 3 个可编辑组合预设，原有 733 个动效保留。演示工程与 CSV 均为明确标注的演示数据，不代表真实研究结论。

## 安装与入口

- macOS 13 及以上，Apple 芯片和 Intel 通用。
- 将「肉呆爱动效-调研预览版.app」拖到 Applications。它使用独立的开发版应用标识，可与正式版共存。
- 此预览包使用本地临时签名，**未经 Developer ID 签名及 Apple 公证**。macOS 可能阻止直接打开；有公证安装要求时请使用 1.3 正式版。
- App 中按 ⌘O 打开安装盘「演示工程与CSV/重构调研-全部模板.dmboard」。先把演示工程复制到本地再编辑保存。
- 点击片段上方动效胶囊，在「调研数据 · Opus」「调研组合预设」中选择。右上角「这一镜」编辑数据、样式、时间线与输出。
- 默认 1920×1080、60fps。模板配置、中文字体、数据与秒级动画逻辑由预览和导出共用。

## 新增内容

前后对比、点阵占比、动态排名、数字变化；看板卡片、问卷、桑基、漏斗、散点气泡、热力日历、原声卡片、追踪时间轴、图片/视频分屏、堆叠面积；个体连续分组、样本拉远、动态解说、城市地图、决策路径、产品场景聚焦；以及三个叙事组合预设。

支持表格与 CSV、统一 AI 配置、撤销重做、保存重开、逐帧 MP4 导出。AI 本地调用和各模板数据口径详见仓库 `docs/OPUS.md`。

产品场景为分层视差；字幕使用导入时间戳或手动时间点，不含自动口播对齐。YouTube 参考未读取连续画面，实现依据需求规格。地图使用本地 Natural Earth 陆地轮廓。

## 构建与验证

源码构建：`tools/run_dev.sh`。生成通用预览安装盘：`tools/build_preview.sh`。

测试：`node tests/opus.mjs`、`node tests/opus_media.mjs`、`PATH="$PWD/.venv/bin:$PATH" tools/check.sh`。

GitHub Release 同时提供全部模板验收视频和示例工程压缩包。
